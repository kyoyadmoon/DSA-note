# Data Structures and Algorithms Interview Resources

## Knowledge

- [MIT OpenCourseWare: 6.006 Introduction to Algorithms, Spring 2020](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)
  University course covering dynamic arrays, hashing, heaps, balanced search trees, graph search, shortest paths, and dynamic programming. Use for definitions, invariants, and asymptotic analysis.
- [MIT OpenCourseWare: 6.006 Lecture Notes](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/resources/lecture-notes/)
  Primary lecture material for individual topics. Use when checking an implementation or complexity claim in a chapter.
- [Algorithms, 4th Edition — Sedgewick and Wayne](https://algs4.cs.princeton.edu/home/)
  Princeton's official companion site covering stacks, queues, priority queues, symbol tables, hashing, trees, and graph algorithms. Use for implementation comparisons and worked examples.
- [Introduction to Algorithms, 4th Edition — MIT Press](https://mitpress.mit.edu/9780262046305/introduction-to-algorithms/)
  Standard reference for rigorous algorithms and data structures. Use for proofs, amortized analysis, and advanced follow-ups.
- [LeetCode Study Plans](https://leetcode.com/studyplan/)
  Structured problem sets for converting each concept into timed coding practice. Use after completing a chapter and its retrieval checks.

## Wisdom (Communities)

- [LeetCode Discuss](https://leetcode.com/discuss/)
  Large interview-practice community. Use to compare solution trade-offs and recent interview experiences, while treating individual posts as anecdotal rather than authoritative.
