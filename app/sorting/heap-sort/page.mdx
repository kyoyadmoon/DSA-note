# Heap Sort

Heap sort 先把陣列解讀成一棵 complete binary tree，建立 **max heap**，再反覆取出根節點的最大值放到陣列右側。它結合 Selection sort「每輪選出極值」的思路與 heap 的快速修復能力，把最壞時間從 `O(n²)` 降到 `O(n log n)`。

## 陣列如何表示 binary heap

對索引 `i`：

```
parent(i) = floor((i - 1) / 2)
left(i)   = 2i + 1
right(i)  = 2i + 2
```

因為 complete binary tree 的每一層由左到右填滿，不需要儲存指標就能由索引找到親子關係。長度為 `n` 時，葉節點從 `floor(n / 2)` 開始，最後一個需要 sift-down 的非葉節點是 `floor(n / 2) - 1`。

## Max-heap property

Max heap 要求每個父節點都大於或等於其子節點。因此全域最大值一定在 `a[0]`，但兄弟節點之間、不同子樹之間不保證有序。

`siftDown(root, end)` 的修復方式：

1. 找出 root 的兩個子節點中較大者
2. 若 root 已不小於較大子節點，這棵子樹符合 heap property
3. 否則交換 root 與較大子節點，沿交換後的位置繼續向下

必須和較大子節點交換；若只和左子節點交換，右子節點可能仍大於新的父節點。

## 兩個階段

### 1. Bottom-up 建立 max heap

從最後一個非葉節點向 `a[0]` 逐一 sift-down。處理索引 `start` 時，它的左右子樹已經是 heap，所以只需把該 root 放到正確高度。

雖然單次 sift-down 最多是 `O(log n)`，建堆總時間不是 `O(n log n)`，而是 `O(n)`：接近底層的大多數節點只能下沉很少層，只有少數靠近 root 的節點能下沉完整高度。

### 2. 反覆取出最大值

建立 max heap 後：

1. 交換 `a[0]` 與 heap 最後一格
2. 右端最大值加入已排序 suffix，不再屬於 heap
3. 對新的 root sift-down，修復縮小後的 heap

每次抽取最多需要 `O(log n)`，共執行 `n - 1` 次，所以排序階段是 `O(n log n)`。

## 複雜度

| 階段 | 時間 |
|---|---:|
| Bottom-up 建堆 | O(n) |
| n - 1 次抽取與修復 | O(n log n) |
| 整體上界 | O(n log n) |

Heap sort 的平均與最壞時間都是 `O(n log n)`，沒有 Quick sort 因分割失衡而退化到 `O(n²)` 的問題。

所有交換都在原陣列內完成，迭代版 sift-down 只使用固定數量的索引與暫存值，所以額外空間是 `O(1)`。

## 為什麼不穩定

把 root 和 heap 尾端做長距離交換時，相等元素可能跨越。即使輸入只有三個相等值：

```
[2a, 2b, 2c]
```

這個實作完成後的身份順序會是 `[2b, 2c, 2a]`。數值排序正確，但相等元素的原始順序改變，因此 Heap sort 不穩定。

## 跟其他 O(n log n) 排序比較

| 特性 | Heap Sort | [Merge Sort](/sorting/merge-sort) | [Quick Sort](/sorting/quick-sort) |
|---|---|---|---|
| 平均時間 | O(n log n) | O(n log n) | O(n log n) |
| 最壞時間 | O(n log n) | O(n log n) | O(n²) |
| 額外空間 | O(1) | O(n) | 平均 O(log n) stack |
| 穩定 | 否 | 是 | 否 |
| 資料區域性 | 較差 | 合併時連續掃描 | 通常較好 |

Heap sort 適合需要 `O(n log n)` 最壞上界、又不能配置 `O(n)` 輔助陣列的情境。實務上若更重視平均常數與 cache locality，陣列排序常採 Quick sort 的混合變形；需要穩定性時則常採 Merge sort 或其他穩定排序。

## 常見延伸

- Priority queue：保留 heap，不必完成排序；插入與取出極值都是 `O(log n)`
- Top K：維護大小為 `k` 的 min heap，處理每個新元素
- Median stream：同時維護 max heap 與 min heap
